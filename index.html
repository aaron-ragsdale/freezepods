JavaScript game editor

Commands: await pods.digitalWrite(1, 0, true), await pods.sound('success'), await pods.light(1, 'blue'), await pods.off(), await pods.wait(500), await pods.waitPress(3000), await pods.addScore(10), await pods.nextRound(), await pods.randomPod(), await pods.message('Hello'). Use for, if, arrays and variables to build games. JavaScript mode is separate from Blocks mode.

Security: programs run inside a sandboxed frame with only the limited FreezePods command interface. This is an early educational sandbox, not a hardened environment for running untrusted third-party code.
